Doppler Effect

What is the Doppler effect?

The Doppler effect occurs when there is relative motion between a wave source and an observer, causing the observed frequency to change. When the source moves towards the observer, the wavefronts are compressed, so the wavelength decreases and the observed frequency increases. When the source moves away, the wavefronts are spread out, so the wavelength increases and the observed frequency decreases.

About this Simulation

This diagram shows a source moving horizontally while Observers A, B, and C remain stationary. The orange arrow shows the source's direction and relative velocity: a longer arrow represents a greater speed, while no arrow is shown when the source is stationary.

When the source moves to the right, Observer C is in front of the source and receives compressed wavefronts. Observer C therefore detects a higher apparent frequency. Observer A is behind the source and receives more widely spaced wavefronts, so detects a lower apparent frequency. The greater the source's velocity, the greater these changes are.

When the source moves to the left, the situation reverses. Observer A is then in front of the source and detects a higher apparent frequency, while Observer C is behind the source and detects a lower apparent frequency.

Observer B is above the source's path. As the source approaches B, B detects a higher apparent frequency. At the instant that the source is directly below B, its motion is perpendicular to the line between the source and B, so there is no Doppler shift in this simplified model. As the source moves away from B, B detects a lower apparent frequency. This shows that the Doppler effect depends on whether the source is moving towards or away from each observer.

When the velocity is set to zero, the source is stationary. All three observers receive evenly spaced wavefronts and detect the emitted frequency.

The wave speed remains constant because the waves travel through the same medium. The source's motion instead changes the spacing of the wavefronts: their wavelength is shorter in front of the source and longer behind it. Using \(v = f\lambda\), if wave speed \(v\) remains constant, a shorter wavelength corresponds to a higher observed frequency, while a longer wavelength corresponds to a lower observed frequency.

Additional Information

How do you calculate the observed frequency?

For a moving source and a stationary observer, the observed frequency can be calculated using:

\[ f' = f\left(\frac{v_w}{v_w \pm v_s}\right) \]

Here, \(f'\) is the observed (apparent) frequency, \(f\) is the frequency emitted by the source, \(v_w\) is the wave velocity, and \(v_s\) is the source velocity.

Use \(v_w - v_s\) in the denominator when the source moves towards the observer. This gives \(f' > f\), so a higher frequency is detected. Use \(v_w + v_s\) when the source moves away from the observer. This gives \(f' < f\), so a lower frequency is detected.

Formula note: This version of the formula applies to a moving source and a stationary observer. All velocities must use the same units.

What happens when the source moves at wave speed?

At \(120\text{ px/s}\) in either direction, the source reaches wave speed (in this simulation). When the source speed reaches the wave speed (\(v_s = v_w\)), the wavefronts in front of the source pile up together because the source catches up with each wave it emitted previously. In the ideal model, the wavelength in front becomes zero and the detected frequency would become extremely large. In reality, this creates a strong pressure disturbance, similar to the beginning of a shock wave.

What happens if the source moves faster than the wave speed?

If the source travels faster than the waves it produces (\(v_s > v_w\)), it is moving supersonically. In this simulation, that means its speed is greater than \(120\text{ px/s}\) in either direction.

The source moves ahead of every wavefront it emits, so the waves cannot spread out in front of it. Instead, the wavefronts overlap and form a V-shaped boundary behind the moving source called a Mach cone.

In air, this overlapping pressure disturbance is a shock wave. When the shock wave reaches an observer, it can be heard as a sonic boom. The faster the source moves, the narrower the Mach cone becomes.

Are the frequency of the emitted waves actually changing?

The source emits waves at a constant frequency. However, because the source moves relative to the observer, the wavefronts are compressed in front of it and spread out behind it. This causes an apparent change in the frequency detected by the observer.

Does the speed of the wave change?

No. The speed of the wave remains constant while it travels through the same medium. For example, sound travels at approximately the same speed through still air regardless of whether the source is moving towards or away from an observer.

The Doppler effect changes the spacing of the wavefronts and therefore the frequency detected by an observer. It does not change the wave speed in the medium.

Why does a greater source velocity cause a greater Doppler effect?

The source emits wavefronts at regular time intervals. At a greater velocity, it travels a greater distance between each emission. This makes the wavefronts more compressed in front of the source and more spread out behind it.

As a result, an observer in front detects a greater increase in frequency, while an observer behind detects a greater decrease in frequency.
